# STM32智能桌面宠物项目

## 功能介绍
本项目基于STM32F103C8T6微控制器，实现了以下功能：
- 5个SG90舵机控制（左前、右前、左后、右后、尾巴）
- 2个呼吸灯效果
- 光敏传感器数据采集（AO模拟量 + DO数字量）
- DHT11温湿度传感器数据采集
- 0.96寸OLED显示屏显示传感器数据
- HC-05蓝牙模块通信，支持舵机控制和数据回传

## 硬件连接

### 舵机连接
| 舵机   | 引脚  | 定时器 |
|--------|-------|--------|
| 左前   | PA0   | TIM2_CH1 |
| 右前   | PA1   | TIM2_CH2 |
| 左后   | PA2   | TIM2_CH3 |
| 右后   | PA3   | TIM2_CH4 |
| 尾巴   | PA6   | TIM3_CH1 |

### 呼吸灯连接
| LED    | 引脚  | 定时器 |
|--------|-------|--------|
| LED1   | PB0   | TIM3_CH3 |
| LED2   | PB1   | TIM3_CH4 |

### 传感器连接
| 传感器 | 功能 | 引脚  |
|--------|------|-------|
| 光敏AO | 模拟量 | PA5 (ADC通道5) |
| 光敏DO | 数字量 | PA7 (上拉输入) |
| DHT11  | 温湿度 | PB7 (单总线) |

### 显示屏连接
| OLED | 引脚 |
|------|------|
| SCL  | PB8  |
| SDA  | PB9  |

### 蓝牙模块连接
| HC-05 | 引脚 |
|-------|------|
| TX    | PB10 (USART3_RX) |
| RX    | PB11 (USART3_TX) |

## 通信协议

### 波特率
115200 bps

### 舵机控制命令
| 命令格式 | 说明 | 范围 |
|----------|------|------|
| LF:角度  | 左前舵机 | 0-180 |
| RF:角度  | 右前舵机 | 0-180 |
| LB:角度  | 左后舵机 | 0-180 |
| RB:角度  | 右后舵机 | 0-180 |
| TA:角度  | 尾巴舵机 | 0-180 |

示例：
- `LF:90` - 将左前舵机设置到90度
- `TA:45` - 将尾巴舵机设置到45度

### 数据回传格式
系统每100ms自动回传一次数据，格式如下：
```
T:温度,H:湿度,AO:光敏模拟值,DO:光敏数字值,LF:左前角度,RF:右前角度,LB:左后角度,RB:右后角度,Tail:尾巴角度
```

示例：
```
T:25.6,H:60.0,AO:2048,DO:1,LF:90,RF:90,LB:90,RB:90,Tail:90
```

## 文件说明
- `main.c` - 主程序文件
- `delay.h/c` - 延时驱动
- `usart.h/c` - USART3串口驱动（蓝牙）
- `oled.h/c` - OLED显示屏驱动（I2C）
- `dht11.h/c` - DHT11温湿度传感器驱动
- `pwm.h/c` - PWM驱动（舵机和呼吸灯）
- `adc.h/c` - ADC驱动（光敏传感器）

## 编译说明
本项目使用Keil MDK-ARM开发环境进行编译：
1. 打开Keil MDK-ARM
2. 导入所有源文件
3. 配置目标芯片为STM32F103C8
4. 编译并下载到开发板

## 注意事项
- 确保所有模块供电正常（3.3V或5V根据模块要求）
- 舵机建议使用外部电源供电，避免电流不足
- 蓝牙模块配对密码通常为1234或0000
